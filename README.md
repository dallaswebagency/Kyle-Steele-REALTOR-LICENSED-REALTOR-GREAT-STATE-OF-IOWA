# Kyle Steele, REALTOR® Homepage

Static homepage for Kyle Steele, REALTOR® with Pinnacle Realty (Iowa).

## Files
- `index.html`: the whole page (HTML, CSS and JS in one file)
- `assets/`: logo and photos

## Publish on GitHub Pages
1. Create a new repo and upload `index.html` and the `assets` folder to the root.
2. Go to Settings > Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
3. The site goes live at `https://<username>.github.io/<repo>/` within a minute or two.

## Before launch
- Replace the stock photos in `assets/` (home-*, town-*, blog-*, hero-farmhouse) with Kyle's approved images, keeping the same filenames.
- Fill in placeholders: listings, stats, reviews, email, office address, Iowa license #, service areas.
- Hook the contact form and home search up to a form service / CRM and MLS/IDX feed (they don't send anything yet).
